# 可复制的任务指令

## 新海报

> 请用 Poster Studio 做一张论文海报。先读论文和原始图，核对作者、机构、数据来源，以及会议要求的尺寸和方向。给我两三个版式预览，确认后制作 poster.html 并启动 localhost。先安排内容和图，再局部调整字号与间距。数字记录论文出处，定稿后交付 PDF、PNG 和源码。

补充：论文路径/原图路径、会议年份、语言、必留/必删、颜色禁忌、公开 QR 目标、个人介绍是否需要。

## 不重做，只改一处

> 保持现有画布、字体、配色、作者信息与所有已确认的决定，只调整【区域/组件】的【问题】。不要重选模板或顺便改别处。用共享 token/组件参数调整，刷新预览；必要时重跑受影响检查。先不永久导出 PDF。如果改动导致重排，请看整体是否仍平衡。已经否决的方案见 DECISIONS.md，不要重新加回来。

## 压缩结果区

> 结果区保留代表性且可比的数字，不做整张论文表。按任务分组，展示任务名、主要值、比较对象和指标。方法提升与表示性质分析分开。正文结论压成一两行，删除不承载事实的小字，但不要删掉必要的实验条件。不加入极端案例，不夸大倍数。

## 终检与交付

> 阅读当前源码、EVIDENCE 和 DECISIONS，核对内容与署名，检查 print 模式和最终 PDF，不以网页缩放预览代替。导出一页指定物理尺寸 PDF、300 DPI PNG、可编辑源码及自包含 HTML，从 PDF 解码二维码。人工查徽章边缘、图标签、个人信息与元数据。只打包最终结果和必需源码/资产，不含笔记、证据、签名、邮件、缓存、中间版本。先交付本地包，不自动发布到外部。
