# 组件与排版旋钮

创建项目后 CSS 会内联进 `poster.html`，只修改项目，不改模板库。

| 调整目标 | 首选位置 |
|---|---|
| 统一配色、字号、留白 | 顶部 `:root` token |
| 编号更显眼 | `--fs-number`，不要逐个写字体大小 |
| 任务名更大 | `.metric h3` 所用 `--fs-heading` |
| 数字更大 | `--fs-metric`；仍保留方法/指标/任务标签 |
| 结果底色 | `--soft`，背景与文字一起检查对比度 |
| 标题与完整标题一行 | `.title-line`，允许较小副标题，不强制 nowrap 溢出 |
| 作者/机构可读性 | `--fs-author`、`.affiliations`；角色统一调大 |
| 所有徽章整体移动 | `.logo-row` 的间距/外边距，不分别绝对定位 |
| 联系方式和介绍 | `.presenter` |
| QR 大小 | `--qr`；标签与槽对齐 |
| 微信等视觉偏重 | `.qr-block.optical-small` 和 `--qr-optical`，保留共同槽高度 |
| 模块间距 | `--gap`，不靠空行和巨大的 margin-top:auto 撑满 |

## 图

宽图通常铺满所属区域；方图/竖图按内容安排，别把所有图强制拉成同一高度。使用 `object-fit:contain` 保留比例，避免 `cover` 裁掉轴标签、边界和校徽。优先 SVG/矢量图，栅格看“打印时的有效 DPI”，不是原始文件看起来很大。

图库或论文图需要记录出处与使用权限。机构/logo 优先官方清晰素材，名字已在机构行时不用再塞复杂文字锁标。浅背景上的 `white-blend` 可以淡化白色矩形；深底请使用清楚的浅色托底，别导致黑色二维码消失。

## 结果卡

三个结构层：任务名 → 关键对比值 → 方法/指标/条件。结论不能靠数字自行解释：分清相对倍数、绝对百分点、F1 分数和百分比。准确度与时延比较需说明相同任务和必要计时条件，不能拿不同硬件/任务的最好数字硬拼。

不放大表也不意味着缺少比较对象；精选实际代表值即可，区域标题正常叫 Results。不要做无限个小卡让字号变细。摘要结论两行是初始目标，不是所有论文的强制上限。

## 字体与数学

模板采用系统常见字体，无 CDN；跨设备字体可能替换，不保证像素一致。有严格一致需求时，依法获取静态字体文件并内嵌，或交付 PDF 作为权威成品。本库轻量 bundler 不支持 CSS url()/@import；要内嵌字体请先转成内联 data 并相应扩展 bundler，不能悄悄留下外网依赖。

公式优先从论文转换为本地 SVG，或使用验证过的原生 MathML。不要直接把 LaTeX `$...$` 当作 HTML 公式。数字与单位避免分离换行，希腊字母不要继承 uppercase。

## 改画布

同时修改 `--page-w/--page-h`、`@page size`、print 中 html/body 宽高，然后重新预算内容和布局；只改 `@page` 会印错。工具读取 `@page` 并按对应物理尺寸导出，但不会自动把内容重新排好。
